# EVERGREEN · 林间守卫

一个基于 React、Vite 和 Canvas 2D 的森林塔防游戏，无需后端或 API 密钥。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm ci
npm run dev
```

默认开发端口为 5173。生产构建：`npm run build`；游戏规则测试：`npm test`。

## 玩法

- 初始 20 点生命、240 金币，守住 10 波敌人即可获胜。
- 选择游侠箭塔（80）、重装炮塔（140）或冰霜法塔（120），在空旷草地放置。道路及相邻塔占用区域禁止建造。
- 箭塔快速单体攻击；炮塔造成范围伤害；冰塔减速 45%，持续 2 秒。
- 击杀敌人与完成波次获得金币。点击防御塔，独立升级伤害与射速，各最多 3 级。
- 出售返还总投入的 70%。第 5、10 波有首领；首领漏过扣 4 点生命，普通敌人扣 1 点。
- 1 / 2 / 3 选塔，Esc 取消，Space 开始波次或暂停。战场可聚焦后用方向键选择位置，Enter 建造。
- 支持 1 / 2 / 3 倍速、暂停、可选击杀音效、重新开始和手机触控。

## 结构

- `src/game.js`：独立于界面的战斗、经济与胜负逻辑。
- `src/renderer.js`：Canvas 游戏渲染。
- `src/main.jsx`：游戏界面与交互。
- `public/art/`：为本游戏生成的地图与透明精灵素材。

游戏状态保存在当前页面内；刷新页面会重新开始。

## 部署到 Render

仓库根目录提供 `render.yaml` Blueprint，用于创建静态站点：

- 分支：`main`
- 构建命令：`npm ci --no-audit --no-fund && npm run build`
- 发布目录：`dist`
- Node.js：`24.19.0`
- 无需应用密钥、数据库或后端服务。

在 Render 中选择 **New → Blueprint** 并连接此 GitHub 仓库，确认静态站点配置后部署。后续 `main` 的提交由 Render 按服务的自动部署设置构建发布。
