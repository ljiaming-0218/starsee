# EVERGREEN · 林间守卫

一款 React + Canvas 2D 的森林塔防游戏。第二版重新制作了战场与指挥界面，并加入完整的兵种克制、专精和主动技能系统；无需后端、数据库或应用密钥。

## 运行与检查

使用 Node.js 24.19.0（与 Render 配置一致）。

```sh
npm ci
npm run dev
npm test
npm run build
```

开发端口为 5173，生产静态文件输出到 `dist/`。测试覆盖伤害抗性、弹道、治疗、连锁、经济、升级专精、存档，以及使用正常金币收入完成 12 波的模拟。

## 战役

- 初始 320 金币。休闲 / 标准 / 老兵分别提供 25 / 20 / 15 点生命和不同的敌人生命倍率。
- 12 个手工编排波次，第 4、8、12 波有首领，最后一波有双首领。
- 6 类敌人：史莱姆、疾行哥布林、重甲圣甲虫、魔抗游魂、治疗萨满、岩石巨像。
- 击杀和守住波次赚取金币，普通敌人漏过扣 1 点生命，巨像漏过扣 5 点。
- 战役自动保存在当前浏览器，战斗中刷新后会暂停等待继续。本机最高分与胜利次数独立保留；重开会覆盖当前战局。

## 防御与专精

| 塔       | 成本 | 职责                    | 专精（二选一）                                     |
| -------- | ---: | ----------------------- | -------------------------------------------------- |
| 游侠箭塔 |   80 | 远程快速单体物理        | 鹰眼神射：增加射程和伤害 / 疾风齐射：攻击 3 个目标 |
| 重装炮塔 |  140 | 范围伤害，部分破甲      | 震地重炮：更大范围和伤害 / 烈焰炮弹：附加持续燃烧  |
| 冰霜法塔 |  120 | 无视护甲，减速 45%      | 永冻之心：更强减速 / 碎冰诅咒：提高目标受到的伤害  |
| 雷电高塔 |  180 | 无视护甲，连锁 3 个目标 | 风暴回响：连锁 5 个 / 雷霆过载：首个目标伤害翻倍   |

伤害和射速各可升级 3 次，累计升级 4 次后解锁专精。每座塔可独立设置攻击最前、最强或最近的敌人。出售返还总投入的 70%。可建造区域与道路、森林、地标分离，标记和射程预览会辅助布置。

## 秘术与操作

- **Q 陨火打击**：选择落点，对 115 范围内的敌人造成魔法伤害；38 秒冷却。
- **W 复苏之风**：立即恢复 4 点生命，不能超过初始上限；55 秒冷却。
- 技能仅在交战时使用，冷却按战斗时间推进；暂停时停止，倍速时加速。
- **1–4** 选塔、**Space** 开波或暂停、**Esc** 取消。
- 聚焦战场后，可用方向键移动格位，Enter 建造或释放秘术。
- 支持手机触控、战斗音效、全屏、敌人图鉴与三星通关评级。

## 结构

- `src/content.js`：兵种、塔、波次、专精和难度配置。
- `src/game.js`：与 UI 独立的确定性战斗与经济逻辑。
- `src/renderer.js`：高像素密度 Canvas 渲染、精灵、弹道与命中特效。
- `src/useGame.js`：帧循环、自动存档、资源加载和交互状态。
- `src/components/`：战场、指挥栏、工坊、图鉴与设置。
- `src/storage.js`、`src/audio.js`：本地保存和轻量合成音效。
- `public/art/`：本游戏生成的地图、塔、敌人和技能素材。
- `DESIGN.md`：参考原则与本次升级的设计取舍。

## Render

仓库根目录的 `render.yaml` 使用静态站点：分支 `main`，Node.js `24.19.0`，构建为 `npm ci --no-audit --no-fund && npm test && npm run build`，发布目录 `dist`。

在 Render 中选择 **New → Blueprint** 并连接本仓库。已有服务的后续发布由其自动部署设置控制。浏览器存档仅保存在本机，不跨设备同步。
