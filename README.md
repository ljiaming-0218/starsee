# EVERGREEN · 像素守卫

一款 React + Canvas 2D 的像素塔防游戏。3 张独立地图、8 类防御塔、16 种专精，共 30 波关卡内容。没有后端、数据库或应用密钥依赖。

## 运行

Node.js 24.19.0，与 Render 配置一致。

```sh
npm ci
npm run dev
npm test
npm run build
```

开发端口 5173，生产输出 `dist/`。规则测试覆盖兵种克制、弹道、毒素、贯穿、喷火、增幅、存档，以及正常经济下三张地图的完整通关。

## 三张关卡

| 关卡     | 波次 | 初始金币 | 设计                                |
| -------- | ---: | -------: | ----------------------------------- |
| 翡翠林道 |    8 |      320 | 长 S 型路线，交叉火力与混合入门兵种 |
| 霜裂峡谷 |   10 |      380 | 较短 U 型回环，护甲、魔抗与治疗混编 |
| 熔火要塞 |   12 |      420 | 多重折返，强化敌人与最终双巨像      |

顶部或底部章节卡可自由选关。进行中的战局切关前会提示确认；切关重置本关金币、塔和波次，已经获得的星级、最高分和胜利次数分别保留。通关后可直接进入下一关。

休闲 / 标准 / 老兵分别提供 25 / 20 / 15 点生命和不同敌人生命倍率。普通敌人漏过损失 1 点生命，巨像损失 5 点。击杀与守住波次获得金币。

## 八种塔

| 塔         | 成本 | 核心机制                         | 专精二选一                      |
| ---------- | ---: | -------------------------------- | ------------------------------- |
| 游侠箭塔   |   80 | 快速单体物理                     | 加射程与伤害 / 同时攻击 3 目标  |
| 重装炮塔   |  140 | 范围爆炸，部分破甲               | 扩大爆炸 / 附加燃烧             |
| 冰霜法塔   |  120 | 魔法减速                         | 强化减速 / 提高敌人承伤         |
| 雷电高塔   |  180 | 连锁 3 个目标                    | 连锁 5 个 / 首目标伤害翻倍      |
| 毒沼炼金塔 |  110 | 毒素叠 3 层，持续 4 秒；抑疗 50% | 范围扩散 / 5 层、6 秒剧毒       |
| 熔芯喷火塔 |  150 | 前方扇区持续攻击并灼烧           | 射程与角度提升 / 增伤并延长燃烧 |
| 穿甲重弩   |  200 | 远射、贯穿 2 目标，忽略一半护甲  | 贯穿 4 目标 / 对巨像双倍伤害    |

伤害和射速各可升级 3 次，累计升级 4 次解锁专精。灯塔的两条升级分别增强伤害光环和射速光环；同类光环只取最高值，不会相乘堆叠。攻击塔可独立选择最前、最强、最近的目标。出售返还总投入 70%。

## 敌人与秘术

6 类敌人分别是史莱姆、疾行哥布林、重甲圣甲虫、魔抗游魂、治疗萨满与岩石巨像。下一波阵容与兵种图鉴可随时查看。

- **Q 陨火打击**：点击落点，在 115 范围造成随波次增强的魔法伤害，38 秒冷却。
- **W 复苏之风**：恢复 4 点生命，不超过初始上限，55 秒冷却。
- 冷却按战斗时间推进，准备阶段和暂停时不推进，倍速时加速。

## 操作与保存

- **1–8** 选塔、**Space** 开波 / 暂停、**Esc** 取消。
- 战场聚焦后可用方向键移动格位、Enter 建造或释放技能。
- 支持手机触控；手机选塔后自动回到战场。
- 当前战局自动保存在本机浏览器，刷新战斗会暂停等待继续，不跨设备同步。
- v3 使用独立存档键；旧版 v2 战局保留在原键中，不覆盖旧数据。历史总分可读取，旧版没有独立关卡星级，不据此虚构关卡成绩。

## 像素表现与代码

地图、塔、敌人和秘术均使用独立像素图像。战场在 500×325 的 Canvas 上绘制后按像素放大，关闭图像平滑，界面使用本地像素英文字体和清晰中文字体。地图资源按关卡缓存；路线、可建区与障碍由各关独立配置。

- `src/levels.js`：关卡路线、波次选择、初始经济与地标。
- `src/content.js`：塔、敌人、专精、难度与基础波次。
- `src/game.js`：独立的战斗、经济与胜负逻辑。
- `src/renderer.js`：像素精灵、攻击特效与范围预览。
- `src/storage.js`：当前战局与分关卡成绩。
- `src/components/`：战场、工坊、章节地图、设置与图鉴。

## Render

`render.yaml` 使用 `main`、Node.js `24.19.0`，构建命令 `npm ci --no-audit --no-fund && npm test && npm run build`，发布目录 `dist`。已有服务是否自动发布取决于 Render 的自动部署设置。
